# Language Notes: Portuguese (PT)

## Target is Brazilian Portuguese, not European
The language code stays bare `pt` (never `pt-BR`/`pt-PT` in the JSON or filename), but the
actual target register is **Brazilian** Portuguese — consistent with the corpus's Bible
version (`ARC`, Almeida Revista e Corrigida, a Brazilian edition). Use natural Brazilian
vocabulary and constructions throughout; avoid European-only forms.

## Second-person address: use você, not tu
Use **você** (with third-person verb conjugation: "você tem", "você é") as the standard
second-person address — this is the Brazilian norm. Avoid **tu** with second-person
conjugation ("tu tens", "tu és"), which reads as European Portuguese (or regional
Brazilian dialect, inconsistent with the rest of the corpus's register). Check this
explicitly when translating dialogue or direct address to the reader (e.g. prayer,
reflection prompts) — it's easy to default to `tu` from habit or from mirroring Spanish
`tú`.
